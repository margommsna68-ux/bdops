## Decisions and integration limits

- Ruling: enroll exact project/server/source/machine UUID in `FLEET_MONITOR_CANARY`; never infer identity from names or cache metadata. Missing enrollment refuses extended monitor writes and heartbeat writes. Cost of an incorrect enrollment is refused canary telemetry; operator must configure actual IDs/UUIDs.
- Ruling: bounded current heartbeat replay only, with project/key uniqueness across current rows. Superseded sequences/epochs are refused rather than keeping an unbounded replay ledger. Cost is a conservative 409 for an old lost ACK; caller reconciles instead of renumbering old observations.
- Implementation ruling (not an additional owner decision): SHA-256 of normalized `host|port`, **excluding protocol and credentials**. This can match an endpoint only. Cost/limit: protocol/auth/configuration correctness cannot be inferred. `appliedConfigurationId` stays null without independent full native proof; HOST evidence never verifies GUEST proxy success.
- Ruling: earning and legacy problem evidence share the optional original earning clock. New native reports null cached problems unless same-source-time evidence exists. Cost is conservative Unknown instead of presenting an old error as new; independent problem timestamp is outside this M1 contract.
- Existing generic `/batch` still refuses selected-server-only members; direct scoped scan/heartbeat routes work. No broadening of permissions or financial quotas was made.
- Missing explicit VM UUIDs remain Unknown. Heartbeats never establish per-VM evidence; Central does not establish agent liveness. Unsupported versions stay Unsupported.
- Native scheduling/timeouts/cleanup, real instance/sequence delivery, rollout/configuration, independent Central-down alerting, CPU/RAM/probe latency and actual Moon05 coverage require integration/canary measurement by the main task. No canary acceptance or fleet-readiness claim is made.

Final review: self-review (no callable local reviewer/subagent tool). Important replay-key issue fixed with a failing regression then passing test. No deferred minor finding. Author self-review is weaker than a fresh independent review; the main task may review the uncommitted diff before integration.

Rollback guidance is in the contract document: disable new publishers/enrollment, revert web code if needed, retain the additive snapshot table and all historical records. No business deletion or reset is required.
